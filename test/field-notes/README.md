# Fabricated field notes -- the second required eval corpus

Short operational records with the properties viki's real use has and this
project's own documentation does not: proper nouns, domain vocabulary whose
spelling differs from how anyone later asks for it (`off fore` where the
question says `right front`), dates, people, places, and open/closed state.

`ops-*` are capture-shaped: tasks, constraints, schedules, alerts, obligations.
`range-*` are observation-shaped: horses, markings, sites, bait stations.

FABRICATED, deliberately. They are modelled on the real thing but invented, so
they can live in a public repo and be quoted in test output without exposing
anyone's actual records. Add to them freely -- the more query shapes they
cover, the more useful they are -- but keep them fabricated.

Used with `../life-by-the-numbers` per QUEUE.md section 0: every retrieval
measurement runs against BOTH, because they fail in opposite directions.
